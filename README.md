# Prepare 2027 – konceptprototype

Klikbar prototype af en fornyet FirstAgenda Prepare: AI-resumé, "Spørg sagen", kommunens hukommelse og et samlet flow fra politisk beslutning til handling i XFlow og Plandisc.

**Live:** https://prepare-koncept.netlify.app

Demo-forløb: Overblik → Forbered (Økonomiudvalget, punkt 3) → Live → Afvikl: start afstemning og godkend → Næste skridt → Opret opgaver → Beslutningssporing.

Nulstil demoen via initialerne øverst til højre → "Nulstil demo".

Fiktive data. Ikke et officielt FirstAgenda-produkt.
